## 五、循环与空转模式

| 模式 | 可判定触发信号 | 熔断动作 |
|---|---|---|
| 环境陷阱重试循环 | 同一探针连续 2 次被判 void，且两次原因同族（超时、写拒、挂死） | 立即更换手段并逐字记录「换法」，同一命令不得第三次原样重跑 |
| 正则口径循环 | 同一轴连续 2 轮出现「探针报缺陷 → 核上下文判假阳性」 | 立案前先读实现与门禁的豁免分支，判据须能在仓内文档找到承诺，否则记观察不立案 |
| 变异落地盲区循环 | 变异后门禁 rc=0，或出现「目标串未找到」类断言异常 | 先打印变异行证明落地；落地不符即 exit 2 并作废该探针，不得据 rc=0 判零发现 |
| 重型扫描重复跑 | 同一目录全量枚举在同一轮或相邻轮出现第 2 次，或单次耗时超过 60 s | 一次枚举加缓存；同类扫描不得重复；重型作业交后台并登记实测耗时 |
| 截断输出误判循环 | 判定所依据的输出来自被 timeout、head、cut、tail 截断的调用 | 截断输出不得用于幂等、计数与通过性判定；须完整落盘后再比对 |
| 管道吞退出码 | 判定语句中出现管道后再取 `$?`，或 rc 与预期语义明显冲突 | rc 必须取自重定向后的命令；发现 rc 与语义冲突时先复核取值位置再改结论 |
| 后台作业失联空转 | 子代理回报「active teammate not found」、进程查询为空，或长跑作业无产物 | 先核产物与摘要再判失败；脱离一律用 `setsid … </dev/null >/dev/null 2>&1 & disown`，日志落总库路径 |
| 环境状态残留循环 | 探针内出现 `export`、`cd`，或探针结束后未核对真实总库条目数 | 一律用 `HOME=… cmd` 前缀与绝对路径；写路径探针结束后必须核对条目数与工作树干净 |
| 核实顺序倒置 | 记录、台账或结论写入早于对应实查命令 | 巡检与结论记录必须在实查之后写入；无实查退出码的条目视为未实查 |
| 收敛口径漂移 | 连续干净轮计数被清零，或收敛判据在同一 run 内被更改 | 口径只在单点声明并以决策号变更；不得为维持连击而放行或临时改判据 |

## 六、面向预设的优化建议（按收益与成本排序）

1. 探针成本分级与重型扫描去重。问题：重型枚举重复执行触发 300 s 超时与 shell 重置（第 760 行）。机制：探针脚本首部声明预估耗时与是否重型；同一脚本内不得对同一目录做两次全量枚举。落地：`skills/dsh-codepunk-workflow/references/rate-limit-adaptation.md` 增「探针成本分级」节，`plans/` 增机械检查（可并入 `plans/verify-battery.sh`）。验收：注入「双重全量枚举」夹具，门禁必须报红。
